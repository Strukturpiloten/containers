## Hosting und technische Anfragedaten

Diese statische Website wird über **GitHub Pages**, einen Dienst von GitHub,
bereitgestellt. Anfragen an diese Domain werden von GitHub und dessen
Auslieferungsinfrastruktur verarbeitet. Eine Unternehmensdomain bedeutet nicht,
dass die Auslieferung ausschließlich aus Deutschland erfolgt.

Beim Abruf einer Seite oder Datei übermittelt Ihr Browser technische
Informationen wie Ihre IP-Adresse, die angeforderte Adresse und
Browserinformationen. Abhängig von den Browsereinstellungen kann dazu auch die
zuvor besuchte Seite (Referrer) gehören. Hosting-Systeme können außerdem den
Anfragezeitpunkt, den Antwortstatus und das übertragene Datenvolumen erfassen.

Diese Daten dienen der Auslieferung der Website, ihrer Verfügbarkeit, der
Fehlerdiagnose und dem Schutz vor Missbrauch. Rechtsgrundlage für die
Bereitstellung eines sicheren und zuverlässigen öffentlichen Katalogs ist
Art. 6 Abs. 1 lit. f DSGVO (berechtigte Interessen). Die technischen Anfragedaten
sind für den Abruf der Website erforderlich.

GitHub erklärt ausdrücklich, dass IP-Adressen von Besuchern aus
Sicherheitsgründen protokolliert und gespeichert werden, auch ohne Anmeldung bei
GitHub. Siehe [GitHub Pages: Datenerhebung](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).
GitHub verarbeitet Daten außerdem für eigene Zwecke der Dienstesicherheit gemäß
seiner [Datenschutzerklärung](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Wir betreiben für diese Website keine zusätzliche Analysedatenbank oder eigene

nennt GitHub als Kriterien den Verarbeitungszweck und gesetzliche Pflichten,

Siehe die [Angaben von GitHub zu Sicherheit und Aufbewahrung](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement#security-and-retention).

Kontaktanfragen werden bis zur Erledigung aufbewahrt, soweit nicht gesetzliche
Aufbewahrungspflichten oder die Geltendmachung, Ausübung oder Verteidigung von
Rechtsansprüchen eine längere Speicherung erfordern.

## Cookies, Browserspeicher und Katalogsuche

Die eigenen Seiten und Skripte dieser Website verwenden keine Cookies, keinen
Local Storage oder Session Storage, keine Analyse- oder Werbedienste, kein
Profiling und keine Tracking-Pixel. Stylesheets und Skripte werden von dieser
Website ausgeliefert; externe Schriftarten oder Einbettungen Dritter werden
nicht verwendet. Der übliche Browser-Cache kann Website-Dateien speichern, um
die angeforderten Seiten bereitzustellen.

Die Suche nach Container-Images und die Filter für Image-Familie und
Betriebsmodus arbeiten ausschließlich lokal mit dem bereits
im Browser geladenen Katalog. Suchbegriffe werden weder an uns noch an einen
externen Suchanbieter gesendet. Die Website hat keine Besucherkonten und kein
Kontaktformular.

Derzeit gibt es kein optionales, einwilligungsbasiertes Tracking, für das ein
Cookie-Banner erforderlich wäre. Werden optionale Speicherzugriffe oder
Tracking eingeführt, erfolgen die Information und gegebenenfalls erforderliche
vorherige Einwilligung vor ihrer Verwendung.
